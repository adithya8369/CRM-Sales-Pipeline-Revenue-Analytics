# CRM Sales Pipeline & Revenue Analytics

A sales analytics project focused on understanding CRM pipeline performance, revenue generation, product concentration, sales-agent performance, and sales-cycle trends using SQL, MySQL, and Power BI.

## Tools Used

- MySQL
- SQL
- Power BI
- Git & GitHub

## Project Overview

This project analyzes 8,800+ CRM sales opportunities to understand how opportunities move through the sales pipeline and how different products and sales agents contribute to revenue.

SQL was used to perform the core analysis, calculate business metrics, and identify sales patterns. The results were then translated into an interactive Power BI dashboard for easier business reporting and analysis.

## Key Analysis & Findings

- Evaluated **8,800+ sales opportunities** and identified a **63.15% closed-deal win rate**, representing **4,238 Won opportunities and $10.01M in realized revenue**.
- Compared win rates across **35 sales agents**, identifying a **15.42 percentage-point variance** between agent win rates.
- Analyzed product-level revenue and found that the **top 2 products accounted for 61.37% of total revenue**, highlighting concentration within the product portfolio.
- Analyzed **6,711 closed opportunities** and calculated an average **48-day sales cycle**.
- Identified **92.05% variation in monthly Won revenue**, showing significant changes in revenue generated across the observed period.
- Built an interactive **Power BI dashboard** covering pipeline conversion, revenue concentration, monthly trends, product performance, and sales-agent efficiency.
